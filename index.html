GoldenGoose Backup

Private Data Backup and Recovery Utility

About

GoldenGoose Backup is a personal, non-commercial utility for securely backing up and recovering software project files and configuration data belonging to its owner.

How It Works

The utility uses Restic for encrypted backups and Rclone for connecting to the owner's Google Drive account through OAuth authorization.

Backup data is encrypted before being stored in Google Drive. The utility is not intended for public use or third-party access.

Privacy

This website does not request account passwords, API credentials, or backup contents. The backup utility is operated locally by its owner.

Read our Privacy Policy

Availability

GoldenGoose Backup is a private-use project. It is not offered as a public backup service.
